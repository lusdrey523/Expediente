# Expediente

Repositorio de trazabilidad documental del Expediente Maestro Migratorio (EMM).

## Principio operativo

GitHub funciona como capa de trazabilidad de cambios, no como sustituto de la evidencia primaria. Los documentos y evidencias deben conservar su origen, integridad, identificación y relación con los hechos del expediente.

- Rama de incorporación: `traceability/EMM-BOOTSTRAP-001`

La estructura inicial podrá ampliarse progresivamente. Ningún módulo posterior debe invalidar la trazabilidad histórica ya registrada.
