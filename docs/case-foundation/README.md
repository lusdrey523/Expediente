# Case Foundation

This directory is the controlled entry point for substantive reconstruction of the audited Expediente Maestro Migratorio source package.

## Current state

The repository governance nucleus is established through PR #10. Documentary reconstruction has not yet incorporated the substantive source package.

## Planned foundation components

- source receipt and baseline linkage;
- evidence register and manifest;
- provenance records;
- fact register;
- documentary index;
- temporal model;
- FACT → EVIDENCE → DOCUMENT relationships;
- verification linkage.

## Integrity rule

No file in this directory should be treated as authoritative merely because it exists here. Each substantive item must retain source identification, provenance and controlled status.
